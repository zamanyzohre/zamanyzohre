# 👩‍💻 زهره زمانی | توسعه‌دهنده وب Full-Stack

سلام! من **زهره زمانی**، توسعه‌دهنده وب با تمرکز بر طراحی و توسعه رابط کاربری و پیاده‌سازی سمت سرور هستم.

در بخش Front-end با فناوری‌هایی مانند React و Next.js و در بخش Back-end با PHP، Laravel و Livewire کار می‌کنم. تجربه توسعه پروژه‌های فروشگاهی، پنل‌های مدیریت و یک سیستم مدیریت ارتباط با مشتریان حوزه املاک (Real Estate CRM) را دارم.

به یادگیری مداوم، نوشتن کدهای قابل نگهداری، حل مسئله و توسعه پروژه‌های کاربردی علاقه‌مندم و به دنبال فرصت‌هایی برای رشد حرفه‌ای و همکاری در تیم‌های توسعه نرم‌افزار هستم.
